Evo Game Engine — Player Integration Guide
PLAYER
🔄 Game Flow — How Your Bot Integrates
1
Register — POST your bot's id, name, and address to /api/players. The address is the HTTP endpoint the game engine will call on your bot.
2
Wait — The admin creates a game (POST /api/game "new"). Two players are picked at random. If selected, your bot will start receiving requests.
3
Receive turn request — The engine POSTs to your address with the game state. You have 1 second (default) to respond.
4
Respond with actions — Return a JSON array of action objects. Respond to every unit you control per turn, or return [] to pass.
5
Game ended callback — When the game ends, the engine POSTs to address + /game-ended with the result. No response needed.
📥 Incoming Turn Request (POST to your bot)

The engine calls POST {your-address} each time one of your units needs to act.

FieldTypeDescription
floorMapbool[][]2-D array — true = walkable tile. Index as [x][y]
unitUnitThe unit that must act this turn
unitsUnit[]All friendly units (your team)
foesUnit[]All enemy units visible to you
{ "floorMap": [[false,true,...], [true,true,...], ...], "unit": { "id":"abc", "type":"dwarf", "health":9, "power":3, "x":3, "y":4 }, "units": [ ... ], // your team "foes": [ ... ] // enemy team }
⚔️ Unit Object
FieldTypeNotes
idstringUnique GUID for this unit instance
typestring"dwarf" or "minotaur"
healthintCurrent HP. Max = 9. Dead when ≤ 0
powerintDamage dealt per attack. Default = 3
xintColumn (0-based, left→right)
yintRow (0-based, top→bottom)
All units of the same type belong to the same player. You own all units in units[].
🎮 Response — Action Array

Return a JSON array. Each object has a type and a direction.

typeEffect
"Move"Move active unit 1 tile in direction
"Attack"Attack the unit in the adjacent tile in direction
directionTile offset
"Up"y − 1
"Down"y + 1
"Left"x − 1
"Right"x + 1
// Move up then attack right [ { "type": "Move", "direction": "Up" }, { "type": "Attack", "direction": "Right" } ]
Return [] to pass. If you time out, your turn is skipped automatically.
🗺️ Map — floorMap Layout

floorMap[x][y] — column-first indexing. true = passable floor. Map dimensions vary per match (admin selects the map).

// Check if tile to the right is walkable const canMoveRight = floorMap[unit.x + 1]?.[unit.y] === true; // Check bounds — always derive size from floorMap itself const mapW = floorMap.length; const mapH = floorMap[0]?.length ?? 0; const inBounds = (x, y) => x >= 0 && y >= 0 && x < mapW && y < mapH; // Find all walkable neighbours const dirs = [{dx:0,dy:-1},{dx:0,dy:1}, {dx:-1,dy:0},{dx:1,dy:0}]; const free = dirs.filter(d => inBounds(unit.x+d.dx, unit.y+d.dy) && floorMap[unit.x+d.dx][unit.y+d.dy]);
🏁 Game Ended Callback (POST to your bot)

Called at POST {your-address} (same endpoint, different body) when the game finishes.

{ "winner": { // null if draw "id": "team-alpha", "name": "Alpha Bot", "score": 3 }, "units": [ ... ], // your surviving units "foes": [ ... ] // enemy surviving units }
Max rounds = 20. If both teams survive, winner is the team with highest total remaining HP. Tie → winner: null.
🤖 Minimal Bot Template (Node.js / Express)
const express = require('express'); const app = express(); app.use(express.json()); // Called each time one of your units needs to act app.post('/', (req, res) => { const { unit, units, foes, floorMap } = req.body; const actions = []; // Attack if enemy is adjacent, otherwise move randomly const dirs = ['Up', 'Down', 'Left', 'Right']; const adjacent = { Up:{x:unit.x,y:unit.y-1}, Down:{x:unit.x,y:unit.y+1}, Left:{x:unit.x-1,y:unit.y}, Right:{x:unit.x+1,y:unit.y} }; const attackDir = dirs.find(d => foes.some(f => f.x===adjacent[d].x && f.y===adjacent[d].y && f.health > 0) ); if (attackDir) { actions.push({ type: 'Attack', direction: attackDir }); } else { const free = dirs.filter(d => floorMap?.[adjacent[d].x]?.[adjacent[d].y]); if (free.length) actions.push({ type: 'Move', direction: free[Math.floor(Math.random() * free.length)] }); } res.json(actions); }); // Called when game ends — no response needed app.post('/game-ended', (req, res) => { console.log('Game over, winner:', req.body.winner?.name); res.sendStatus(200); }); app.listen(3000, () => console.log('Bot listening on :3000'));
